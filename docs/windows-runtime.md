# Windows 接入和处理位置 · 0.2.1

网页连接云端实例时，文件上传到服务器并在那里处理；安装 CLI/MCP 调用包不会自动把计算搬到用户电脑。本机处理必须运行本机媒体服务，并在该实例核对实际工具与模型。

Windows 依赖指引已分别覆盖 FFmpeg/FFprobe、Poppler、Tesseract 和 LibreOffice，不再返回 macOS 的 brew 命令。更改 PATH 后需重启本机媒体服务，诊断状态才反映新环境。中文水印字体优先使用显式 MEDIAFORGE_FONT，其次检查 Windows 字体目录中的微软雅黑、黑体和宋体。

本次没有将全部媒体引擎、系统处理器和可选模型打成 Windows 一键安装器；下载页面与统一工作台明确标识“命令行与 AI 调用包”。语音转写、抠图等模型仍按 MODELS.md 准备，并按实际依赖状态显示可用性。

本机回归 53 项通过、2 项可选模型跳过。测试时默认 Homebrew FFmpeg 缺少 x265 动态库，采用已安装的 ffmpeg-full 路径进行本次进程内验证，未改变系统全局链接或其他项目环境。新增 Windows 指引与字体优先级回归通过；没有宣称实际 Windows 引擎行为已验证。
