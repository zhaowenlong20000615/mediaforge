# UI 方向与交互取舍

借鉴Linear的任务状态与工作区导航、文件管理器的文件列表/排序/结果操作、成熟导出工具的参数表单和进度反馈。只借鉴交互方式，不使用其品牌资产或代码。

本项目采用暖纸色、墨蓝与朱砂的安静工业风格；移除0.1大标语和孤立指标，工具选择后直接配置文件/参数。结果页面展示真实尺寸、时长、页数、逐项状态与内容确认提示。保留搜索与五项导航，窄屏目录限制高度，所有核心动作仍可访问。错误说明下一步，断网保留上下文，文件名使用纯文本防注入。

页面检查覆盖桌面、390px窄屏、键盘可达性、真实上传/参数/创建/结果预览/下载/继续处理、失败与恢复、筛选和登录边界。具体证据见修复验证报告。
